# R15 — Core acceptance and truthful UI

Date: 2026-11-19. Branch: `feat/r15-core-acceptance-honest-metrics`, based on R14 `9786edd`. Local implementation/verification only; no push, PR, merge or deployment.

Source commits: `74c0282` (UI/artwork) and `b8912a6` (browser/CI gates). The passing result records this source revision and script hashes.

## Completed scope

- Campaign counts were already API-derived in R06. They now render exact current values as a semantic definition list, without counting through invented intermediate values. Unavailable data stays distinct from a real zero. Number/label columns can wrap at mobile widths.
- Removed the proven-unused `TimeSelect` component; the mounted campaign page has no inert year selector. The Admin dashboard now links to the three implemented management workflows instead of presenting placeholder overview text or fabricated analytics. Login no longer displays placeholder branding text, and its labeled fields have appropriate names, native required validation and password-manager autocomplete.
- Homepage carousel uses the same three existing photographs, packaged byte-for-byte with source/size/hash provenance. It starts stationary, permits explicit start/stop, pauses for pointer/keyboard interaction, labels every control, exposes selection state and keeps controls/thumbnails reachable on narrow screens. Existing colors/artwork and desktop hero sizing are retained. The new `check:assets` verifies source/build map assets and all homepage copies; CI runs it too.
- Confirmed fixed-width team timeline content could place the public team link outside mobile content. Pin/spacing/image/button layout now adapts below desktop widths; a focused card remains visible instead of fading away. Timeline/artwork and desktop dimensions remain.
- Leader account disclosure reports expanded state, moves focus to its actual action, closes with Escape/blur and restores its trigger. Logout reuses the existing native `EditorDialog` with compact sizing and an explicit safe initial focus target ("Không"). Native Tab/Shift+Tab trapping, Escape and focus return are verified in Chromium. A debug console statement was removed.
- Route changes scroll immediately and move focus to the new heading, including asynchronous data rendering. They respect an opened modal/disclosure and later user focus, avoiding a confirmed race where route focus could interrupt the account action. Permission denial is announced as an alert.

No API, database schema, authorization policy, map-marker identity/loading or persistence behavior changed. No prototype or general redesign was created. Unmounted legacy/mock modules were not imported into shipped routes.

## Delivered behavior

- Campaign, team and post reads now use the existing Axios client and the R04 shared read DTOs. Removed mock imports and simulated delays from these adapters. Cancellation signals reach Axios; HTTP status is retained for missing-resource handling.
- Home discovers actual campaigns, including their numeric IDs, names, dates and attachments. Its empty/error/loading states do not substitute sample campaigns. The footer points to campaign discovery instead of a stale slug.
- Campaign lists request `teams?campaignId=...` and `posts?campaignId=...`. Team activity requests include both campaignId and teamId. Query keys carry these filters; navigation between campaigns cannot reuse another campaign's list key.
- Descriptions, team images/attachments, commander names and post thumbnails come from DTOs. Missing data gets explicit missing-information text; there are no invented commander profiles. The team gallery renders every distinct supplied image, rather than truncating after three.
- Campaign/team activity cards link to the selected post's ID. Public routes `/campaign/:campaignId/post/:postId` and `/campaign/:campaignId/team/:teamId/post/:postId` load the detail/photos independently, survive reload and reject mismatched campaign/team context. Canonical positive numeric route IDs are required.
- Detail reuses the existing warm two-panel appearance as a page, with always-visible gallery controls. It shows ordered API photos, actual title/content/team/date and nullable author. Close uses the originating list when reached through a card, with a parent-list fallback for direct entry. No location/share behavior is invented where the contract supplies none.
- Reusable pending/error/empty/retry states announce pending/error results. A 404 is distinct from a recoverable server/network failure. Prefix query keys permit later write flows to invalidate related reads; the test demonstrates list refresh after invalidation. Guest has no mutation flow, so actual write-to-refetch behavior remains R07/R09.
- Campaign header section links wait for asynchronously loaded sections before scrolling and observing the active section. A cold transition from post detail to campaign activities no longer loses its anchor while the API is pending.

No backend, database schema, migration, dependency or map data-loading change is included. Existing Leader/Admin mock models and unfinished write screens remain outside this Guest workstream. Map clicks no longer open the first unrelated mock post: the page explicitly directs visitors to the real activity list until R06 binds marker identity. Static year/statistics are explicitly labeled as illustrative.

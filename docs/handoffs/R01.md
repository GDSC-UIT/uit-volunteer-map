## Final implementation

1. **Built shared package:** ESM exports target `dist/index.js` and declarations. Root build orders shared -> backend -> frontend. Source migration/seed/backend development commands build shared first. The documented shared watcher rebuilds edited source.
2. **One database configuration:** source, compiled runtime, CLI and seeds use the same backend root. Relative paths resolve against `packages/backend`; the default remains `src/data/database.sqlite`. `DB_PATH` precedes the `DATABASE_PATH` alias. Absolute paths and `:memory:` work. Source/compiled globs select .ts/.js migrations respectively.
3. **Startup validation:** existing R01 PORT/JWT validation and reflect-metadata initialization remain intact. No automatic data relocation, reset or synchronization was added.
4. **Windows npm subprocess fix:** smoke uses npm's supplied `npm_execpath` with `process.execPath` and argument arrays, without a shell or hard-coded npm installation path. Invoke through `npm run test:smoke`. Invalid npm CLI configuration fails clearly.
5. **Reliable cleanup:** no `process.exit()` bypasses smoke cleanup. The runner tracks its own children, captures launch errors, checks exit codes, bounds build/migration/seed/health waits and cleans up in `finally`. Windows termination targets recorded PIDs and descendants; Unix uses owned process groups with TERM/KILL escalation. Signal handlers request cleanup. Cleanup errors fail the check.
6. **Fresh artifacts:** every smoke invocation runs root `build:backend` once, compiling current shared/backend source before testing. Compiled commands no longer trigger another shared build.
7. **Compiled-only commands:** `migration:run:dist`, `migration:revert:dist` and `seed:dist` consume prepared JS without shared TypeScript source. Source-level prerequisites remain.
8. **Safe smoke resources:** an owned system-temp directory contains the disposable SQLite DB. Both database variables are overridden. After migration/seed/start/health, cleanup validates the absolute deletion target, stops children, removes the directory and verifies the developer DB hash. Success is printed only after cleanup.
9. **Accurate documentation:** CONTRIBUTING describes environment setup, multi-terminal watch and smoke. It no longer claims the sequential workspace runner starts all packages concurrently. MIGRATIONS distinguishes source commands from prepared-artifact commands and includes PowerShell guidance.
